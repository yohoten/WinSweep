快速上手

三步开始使用

1

安装 Python 3.8+

前往 python.org 下载安装，勾选「Add Python to PATH」。

2

双击启动

直接双击 WinSweep.pyw，程序自动弹出 UAC 请求管理员权限；也可右键「以管理员身份运行」。

3

按需使用

日常选「⚡ 快速清理」，定期选「🚀 深度清理」，精简系统用「📦 系统预装清理」，调优用「🧰 系统优化」。

⌨️ 快捷键

F5 刷新时间与磁盘信息  ·  Ctrl + L 清空日志  ·  Ctrl + C 复制全部日志

📄 技术栈

纯标准库实现，仅依赖 tkinter + Python 内置模块（os / shutil / subprocess / ctypes / threading / queue 等），无需 pip install。
