# 🧹 WinSweep

Windows 系统垃圾清理与优化工具（图形界面版）

基于 Python 标准库 `tkinter` 编写，双击即用、零第三方依赖；集成 **Win11Debloat**（系统预装应用清理）与 **Neon 优化包**（系统性能优化），一站式完成日常缓存清理、系统精简与性能调优。

> ⚠️ 本工具绝大多数操作需要**管理员权限**，程序启动时若检测到未提权会自动弹出 UAC 请求。

## ✨ 功能特性

### 🧹 清理模块（14 项清理项，支持 快速 / 深度 / 自定义 三种模式）

| 分组 | 清理项 |
| --- | --- |
| 缓存清理 | 系统根目录临时文件、Windows 临时目录、用户临时文件、回收站、浏览器缓存（Edge / Chrome / INetCache）、最近文档记录、预读取文件、缩略图缓存、DNS 缓存、Windows 错误报告、剪贴板 |
| 系统维护 | Windows 更新缓存（自动停止/重启 wuauserv、bits 服务）、内存转储文件（MEMORY.DMP / Minidump / LiveKernelReports）、字体缓存（自动停止/重启 FontCache 服务） |

- **快速清理**：一键执行 8 项常用安全缓存
- **深度清理**：全部 14 项 + Windows.old 残留检查
- **自定义清理**：分组勾选，含"全选 / 推荐 / 取消全选"
- 清理前后磁盘空间自动对比，直观显示本次释放空间

### 📦 系统预装清理（集成 Win11Debloat）

- **3 个快速预设一键执行**（静默模式，含二次确认）：
  1. 仅移除默认预装应用
  2. 禁用遥测、必应、广告与建议
  3. 默认模式（官方常用组合：移除预装应用 + 隐私/任务栏/资源管理器优化）
- **完整图形界面入口**：打开 Win11DebloatGUI，可精确勾选要执行的优化项
- 启动前自动备份 `CustomAppsList / SavedSettings` 到 `data/win11debloat_backup/`（保留最近 5 份）
- 记录最近一次清理时间；GUI 关闭后自动刷新磁盘信息

### 🧰 系统优化（Neon 优化包，按危险等级标注）

统一入口管理 `resources/Optimization/` 下全部优化资源，每项支持 **打开目录 / 查看说明 / 执行入口**（reg 导入、bat/cmd/ps1 脚本、exe/lnk 启动），执行前均有二次确认，**高危项**会强化提示建议先建还原点：

| 优化项 | 危险等级 |
| --- | --- |
| 系统备份（Dism++） | 中危 |
| 彻底关闭 WinDefender | ⚠️ 高危 |
| 电源与 CPU 优化（Neon 电源计划 / 大小核） | 中危 |
| 设备管理（DeviceCleanup） | 中危 |
| 游戏性能优化（Gamebar / N 卡高频 / DesktopHeap） | 中危 |
| 键鼠优化（响应 / USB 轮询率） | 低危 |
| 服务与更新管理（关闭/开启 Win 更新、关闭无用服务） | ⚠️ 高危 |
| 内存 / 硬盘 / 网络优化 | 中危 |
| 中断机制与延迟优化（HPET / intMOD / MSI） | ⚠️ 高危 |
| 应用优先级（进程优先级 / CPU 亲和性） | 中危 |

### 🛠 系统工具

- 磁盘清理工具（cleanmgr）
- DISM 组件清理（WinSxS）
- 系统文件检查（sfc /scannow）
- 磁盘错误检查（chkdsk /f，下次重启执行）

### 💽 磁盘信息

- 启动即显示磁盘总大小 / 已用 / 可用
- 常驻信息栏磁盘摘要 + 容量可视化进度条
- 自动检测 `Windows.old` 残留目录并提示清理

## 🚀 使用方法

1. 确认系统已安装 **Python 3.8+**（官方安装包默认自带 `tkinter`）
2. **右键 → 以管理员身份运行** `SystempClean.pyw`（或直接双击，程序会自动请求 UAC 提权）
3. 按需选择功能：
   - **⚡ 快速清理**：日常 8 项安全缓存
   - **🚀 深度清理**：全部 14 项 + Windows.old 检查
   - **🎯 自定义清理**：分组勾选
   - **📦 系统预装清理**：移除 Win11 预装应用 / 隐私优化
   - **🧰 系统优化**：Neon 优化包（注意危险等级）
   - **🛠 系统工具**：cleanmgr / DISM / sfc / chkdsk

### 快捷键

## 🧩 技术要点

- **纯标准库**：仅 `tkinter` + 内置模块（`os / shutil / subprocess / ctypes / threading / queue` 等）
- **线程化执行**：清理任务在后台线程运行，主界面不卡顿；消息经队列中转，UI 批量刷新
- **高 DPI 适配**：自动 `SetProcessDpiAwareness`，缩放屏下界面不模糊
- **性能优化**：移除全盘 `os.walk` 扫描，改为固定路径 / 仅根目录扫描；子进程调用合并，避免重复启停服务
- **日志防膨胀**：最多保留 800 行，超限自动截断前半
- **内置图标**：无 `icon.ico` 时用逐像素绘制的"扫帚"图标，零外部依赖
- **危险操作防护**：系统优化按低/中/高危分级标注，执行前强制二次确认；脚本执行时自动禁用按钮防误点

## ⚠️ 注意事项

1. **务必先备份**：高危优化（关闭 Defender、关闭 Windows 更新、中断延迟优化等）建议先创建系统还原点或使用 Dism++ 备份。
2. **系统预装清理不可逆**：移除的应用可从 Microsoft Store 重新安装，但部分设置项删除后需手动恢复；执行前程序会自动备份 Win11Debloat 配置。
3. **DISM / sfc 耗时较长**（15-30 分钟），请耐心等待，勿强制关闭。
4. `chkdsk /f` 需重启后执行；`net stop/start` 清理更新缓存期间网络更新服务会短暂中断。
5. 清理后个别应用（如浏览器）可能需要重启才能完全生效；Win11Debloat 部分设置需重启系统。
6. 程序目录支持整体移动/复制；**请勿删除 `resources/`**，否则系统预装清理与系统优化功能不可用。
