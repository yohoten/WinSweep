# 🧹 WinSweep

> Windows 系统垃圾清理与一站式优化工具 · v3.3

基于 Python 标准库 `tkinter` 编写，**双击即用，零第三方依赖**。集成 **Win11Debloat**（系统预装应用清理）与 **Neon 优化包**（系统性能调优），覆盖日常缓存清理、系统精简、性能优化全流程。

![preview](https://picui.ogmua.cn/s1/2026/08/14/6a7f2b178f9b2.webp)

> ⚠️ 绝大多数操作需要**管理员权限**，程序启动时未提权会自动弹出 UAC 请求。

## ✨ 功能详情

### 🧹 缓存清理

**14 项清理项**，执行前后自动对比磁盘空间，完成后状态栏常驻显示释放量。

| 分组 | 清理项 |
|---|---|
| 缓存清理 | 系统根目录临时文件、Windows 临时目录、用户临时文件、回收站、浏览器缓存、最近文档记录、缩略图缓存、DNS 缓存、Windows 错误报告、剪贴板 |
| 系统维护 | Windows 更新缓存、内存转储文件、字体缓存 |
| 可选 ⚠️ | 预读取文件（清理后首次冷启动略慢，Windows 自动重建，日常不建议勾选） |

**三种清理模式：**

- **⚡ 快速清理** — 一键执行 7 项常用安全缓存，日常使用推荐
- **🚀 深度清理** — 全部 14 项 + Windows.old 残留检查
- **🎯 自定义清理** — 分组勾选，含「全选 / 推荐 / 取消全选」；推荐预设自动排除可选危险项；可选项以黄色标注并附风险说明

**浏览器缓存动态检测：** 自动扫描本机已安装浏览器，支持 Edge、Chrome、Brave、Opera、Opera GX、Vivaldi、INetCache 等，仅清理实际存在的路径，日志输出命中列表。

### 📦 系统预装清理

集成 [Win11Debloat](https://github.com/Raphire/Win11Debloat)，一键移除 Windows 11 预装应用与隐私相关功能。

**3 个快速预设（静默执行，含二次确认）：**

1. 仅移除默认预装应用
2. 禁用遥测、必应搜索、广告与建议
3. 默认模式（官方常用组合：移除预装应用 + 隐私/任务栏/资源管理器优化）

**完整图形界面入口：** 打开 Win11DebloatGUI，精确勾选每一项执行内容。

- 执行前自动备份 `CustomAppsList / SavedSettings` 到 `data/win11debloat_backup/`（保留最近 5 份）
- 记录最近一次清理时间，启动时显示在日志区
- GUI 关闭后自动刷新磁盘信息

### 🧰 系统优化（Neon 优化包）

统一管理 `resources/Optimization/` 下的 10 类优化资源，每项支持：

- 📂 **打开目录** — 在资源管理器中浏览相关文件
- 📄 **查看说明** — 用记事本打开说明文档（建议操作前必读）
- ▶ **执行入口** — 一键运行（reg 导入 / bat·cmd 脚本 / ps1 脚本 / exe·lnk 启动）

所有执行操作均有**二次确认弹窗**，高危项会强化提示并引导先创建系统还原点。

| 优化项 | 危险等级 | 说明 |
|---|:---:|---|
| 系统备份（Dism++） | 🟡 中危 | 系统镜像备份与还原 |
| 彻底关闭 WinDefender | 🔴 高危 | 不可逆，务必先关实时保护与篡改防护 |
| 电源与 CPU 优化 | 🟡 中危 | Neon 电源计划 / 注册表优化 / 大小核调度 |
| 设备管理 | 🟡 中危 | DeviceCleanup 清理未使用设备 |
| 游戏性能优化 | 🟡 中危 | 注册表优化 / 禁用 Gamebar / N 卡高频 / DesktopHeap |
| 键鼠优化 | 🟢 低危 | 响应注册表 / USB 轮询率 |
| 服务与更新管理 | 🔴 高危 | 关闭/开启 Windows 更新 / 禁用无用服务 |
| 内存 / 硬盘 / 网络优化 | 🟡 中危 | PowerShell 一键脚本 + 注册表导入 |
| 中断机制与延迟优化 | 🔴 高危 | 关闭 HPET / USB 中断仲裁 / MSI 信号亲和 |
| 应用优先级 | 🟡 中危 | 进程优先级 / CPU 亲和性注册表 |

## 🚀 使用方法

**1. 确认已安装 Python 3.8+**

前往 [python.org](https://www.python.org/downloads/) 下载安装，安装时勾选「Add Python to PATH」。

**3. 按需使用**

| ⚡ 快速清理 | 日常使用，7 项安全缓存，一键完成 |

| 🧰 系统优化 | 性能调优（注意危险等级，高危操作先建还原点） |

## 🧩 技术实现

- **纯标准库**：仅依赖 `tkinter` + Python 内置模块（`os / shutil / subprocess / ctypes / threading / queue / tempfile / glob` 等），无需 `pip install`
- **线程化执行**：清理任务在后台线程运行，主界面不卡顿；所有消息经 `Queue` 中转，主线程批量刷新 UI
- **高 DPI 适配**：启动时调用 `SetProcessDpiAwareness(1)`，缩放屏下界面清晰不模糊
- **性能优化**：移除全盘 `os.walk` 扫描，改为固定路径 / 仅根目录扫描；服务 stop/start 合并为单次子进程调用，避免重复启停
- **日志防膨胀**：最多保留 800 行，超限自动截断前半段，长时运行不卡顿
- **内置图标**：无 `icon.ico` 时逐像素绘制扫帚图标，零外部依赖，开箱即用
- **危险操作防护**：系统优化项按低 / 中 / 高危分级标注，执行前强制二次确认弹窗；高危项引导用户先创建系统还原点；执行期间所有操作按钮自动禁用（退出按钮始终可用）
- **浏览器动态检测**：扫描 11 个候选路径，仅处理本机实际安装的浏览器，去重后输出命中列表
- **还原点一键创建**：PowerShell `Checkpoint-Computer` 封装，支持自定义描述，失败时详细回显并引导手动开启系统保护

## ⚠️ 注意事项

1. **高危操作前务必备份**  
   关闭 Defender、禁用 Windows 更新、中断延迟优化等高危项，建议先通过「🛠 系统工具 → 🛡 创建系统还原点」备份，或使用 Dism++ 备份系统镜像。

2. **系统预装清理部分操作不可逆**  
   移除的应用通常可从 Microsoft Store 重新安装，但部分隐私 / 注册表设置项删除后需手动恢复。执行前程序会自动备份 Win11Debloat 配置文件。

3. **DISM / sfc 耗时较长**  
   通常需要 15–30 分钟，请耐心等待，不要强制关闭程序或窗口。

4. **部分清理需要重启生效**  
   `chkdsk /f` 需在下次重启时执行；浏览器缓存清理后建议重启浏览器；Win11Debloat 部分设置需重启系统。

5. **更新缓存清理期间网络更新服务短暂中断**  
   程序会自动停止 `wuauserv` / `bits` 服务、清理后再重启，期间 Windows Update 相关功能暂时不可用。

6. **请勿删除 `resources/` 目录**  
   系统预装清理与系统优化功能依赖此目录，删除后对应功能不可用。整个项目目录支持直接复制或移动到任意位置使用。
